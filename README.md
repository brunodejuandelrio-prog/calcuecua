# Calcuecua Universal 🚀

¡Bienvenido a **Calcuecua Universal**, la calculadora matemática inteligente de ecuaciones online y gratuita!

Esta aplicación web está diseñada para resolver expresiones algebraicas, simplificar operaciones y resolver ecuaciones al instante, funcionando de manera 100% local (Estilo Pythonista) gracias a la tecnología WebAssembly y SymPy.

## ✨ Características principales
- **Calcuecua de ecuaciones**: Resuelve ecuaciones de primer grado, segundo grado y sistemas complejos de forma automática.
- **Multiplicación inteligente**: No necesitas escribir el asterisco `*`, la app detecta expresiones como `2x` o `3(x+1)` de forma automática.
- **Potencias sencillas**: Soporta el uso de `^` o la palabra `power` para elevar números automáticamente (`x^2`).
- **Fracciones exactas**: Olvídate de los decimales infinitos, los resultados se muestran en fracciones limpias y exactas.
